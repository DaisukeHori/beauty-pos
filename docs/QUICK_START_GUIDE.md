# Beauty POS クイックスタートガイド

**とりあえず今すぐ使いたい方向けの最短ガイドです。**

---

## 🚀 5分で始める基本操作

### Step 1: ログイン
1. ブラウザでシステムURLにアクセス
2. メールアドレスとパスワードを入力
3. 「ログイン」をクリック

---

### Step 2: 予約を入れる

```
ホーム画面 → カレンダーの空き時間をクリック → 予約情報を入力 → 保存
```

| 入力項目 | 説明 |
|---------|------|
| 顧客 | 既存顧客を選択 or 新規登録 |
| メニュー | 施術内容を選択 |
| スタッフ | 担当者を選択 |
| 日時 | 予約日時（自動入力済み） |

---

### Step 3: 来店受付

```
ホーム画面 → 予約の「チェックイン」ボタンをクリック
```

予約済みのお客様が来店したら、これだけでOK！

---

### Step 4: 会計

```
施術完了 → 「会計へ」ボタン → 支払方法を選択 → 「会計確定」
```

**支払方法の選択肢：**
- 現金
- クレジットカード
- 電子マネー
- QRコード決済

---

## 📋 これだけ覚えればOK！基本3操作

### ① 新規予約
1. ホーム画面のカレンダーで日時をクリック
2. 顧客・メニュー・スタッフを選択
3. 「保存」

### ② 来店チェックイン
1. ホーム画面で該当予約を見つける
2. 「チェックイン」ボタンをクリック

### ③ 会計処理
1. 「会計へ」ボタンをクリック
2. 金額を確認
3. 支払方法を選んで「会計確定」

---

## ⚡ よくある操作クイックリファレンス

| やりたいこと | 操作 |
|-------------|------|
| 予約を入れる | ホーム → カレンダークリック → 入力 → 保存 |
| 予約を変更する | 予約クリック → 編集 → 保存 |
| 予約をキャンセル | 予約クリック → キャンセル → 理由選択 |
| 来店受付 | 予約 → チェックイン |
| 予約なし来店 | ホーム → ウォークイン |
| 会計する | 会計へ → 支払方法選択 → 確定 |
| 顧客を探す | 顧客管理 → 検索ボックス |
| 今日の売上確認 | ホーム画面のダッシュボード |

---

## 🎯 予約なしのお客様（ウォークイン）

1. ホーム画面 → 「ウォークイン」ボタン
2. 顧客を選択（または新規登録）
3. メニューとスタッフを選択
4. 「開始」をクリック

施術後は通常通り会計へ進みます。

---

## 💡 覚えておくと便利なこと

### 会計時のオプション
- **割引**: 会計画面 → 「割引」ボタン
- **クーポン使用**: 会計画面 → 「クーポン適用」
- **ポイント使用**: 会計画面 → 「ポイント使用」

### 顧客の新規登録
予約画面で顧客選択時に「＋新規顧客」をクリックすれば、その場で登録できます。

### キャンセル料について
- **48時間前まで**: 無料
- **24〜48時間前**: 30%
- **24時間以内**: 50%
- **無断キャンセル**: 100%
