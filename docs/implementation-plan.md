## 12. 開発環境セットアップ手順

```bash
# 1. リポジトリクローン
git clone <repository-url>
cd beauty-pos

# 2. 依存関係インストール
pnpm install

# 3. 環境変数設定
cp .env.example .env
# .envを編集してSupabase等の認証情報を設定

# 4. Supabaseローカル起動
npx supabase start

# 5. DBマイグレーション実行
npx supabase db reset

# 6. 開発サーバー起動
pnpm dev
```
