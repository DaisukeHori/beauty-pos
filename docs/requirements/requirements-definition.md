## 1. システム概要

### 1.1 目的
美容室における売上管理・生産性管理・顧客管理・予約管理を統合し、AI分析による売上向上を実現する高度なPOSシステムを構築する。

### 1.2 特徴
- **売上と生産性の分離管理**: 担当者（売上）と作業者（生産性）を別々に計上
- **高度な顧客カルテ**: 会話AI分析、ヘアスタイル提案、来店予測
- **汎用タグシステム**: あらゆるエンティティに階層化タグを適用可能
- **リアルタイムAI提案**: 施術中のアップセル・クロスセルタイミング検知
- **300種類以上の分析**: 多角的な経営分析ダッシュボード

## 3. マルチテナント設計

### 3.1 テナント構造
```
契約（Company）
├── 店舗A
│   ├── スタッフ
│   ├── 顧客
│   └── 売上
├── 店舗B
│   ├── スタッフ（店舗Aと掛け持ち可能）
│   ├── 顧客（店舗間で共有可能）
│   └── 売上
└── 本部ダッシュボード（全店舗集計）
```

### 3.2 RLS (Row Level Security)
- 契約（Company）単位でデータを完全分離
- 店舗間のデータ共有は同一Company内のみ許可
- スタッフは複数店舗にタグで所属可能

### 4.3 会計管理

#### 4.3.1 売上・生産性の分離
```
1回の施術
├── 売上 → 主担当者（100%）
├── 指名区分 → 本指名 / フリー
├── 指名料 → スタッフごとに設定
│
└── 生産性 → 各作業工程の担当者に按分
    ├── お流し → 担当者A (100%)
    ├── カット → 担当者B (100%)
    ├── カラー塗布 → 担当者B (70%) + 担当者C (30%)
    ├── シャンプー → 担当者C (100%)
```
