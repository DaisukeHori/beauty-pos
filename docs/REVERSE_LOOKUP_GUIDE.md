# Beauty POS 逆引きガイド

「〜したいときはどうする？」形式で、目的から操作方法を探せるクイックリファレンスです。

---

## 📅 予約関連

### 新規予約を入れたい
1. **ホーム画面** → カレンダーの空き時間をクリック
2. または **予約管理** → 「＋新規予約」ボタン
3. 顧客・メニュー・スタッフ・日時を選択して保存

### 予約を変更したい
1. **ホーム画面** または **予約管理** で該当予約をクリック
2. 「編集」ボタン → 内容を修正 → 「保存」

### 予約をキャンセルしたい
1. 該当予約をクリック → 「キャンセル」ボタン
2. キャンセル理由を選択
3. キャンセル料が自動計算される（48時間以内で発生）

### 今日の予約一覧を見たい
- **ホーム画面** に今日の予約が時系列で表示

### 特定の日の予約を確認したい
- **ホーム画面** → カレンダーで日付を選択
- または **予約管理** → 日付フィルターで絞り込み

### 予約が重複していないか確認したい
- システムが自動でチェック（重複時は警告表示）
- **スタッフ別表示**で各スタッフの予約状況を確認

### 予約のリマインダーを送りたい
- 予約詳細画面 → 「通知を送信」ボタン
- 自動リマインダーは設定画面で有効化

## 🚶 来店・受付関連

### お客様が来店したことを記録したい
1. **ホーム画面** → 該当予約の「チェックイン」ボタン
2. または予約詳細画面 → 「来店受付」

### 予約なしの来店（ウォークイン）を受け付けたい
1. **ホーム画面** → 「ウォークイン」ボタン
2. 顧客情報を入力（新規 or 既存顧客選択）
3. メニューとスタッフを選択

### 施術を開始したい
- 来店受付後、自動で施術開始状態に
- または「施術開始」ボタンをクリック

### 施術が完了したことを記録したい
- 来店詳細画面 → 「施術完了」ボタン

## 💰 会計関連

### 会計処理をしたい
1. 施術完了後 → 「会計へ」ボタン
2. または **会計画面** で顧客を選択
3. 内容確認 → 支払方法選択 → 「会計確定」

### メニューを追加したい（施術後）
1. 会計画面 → 「＋商品追加」ボタン
2. 追加するメニュー/商品を選択

### 割引を適用したい
1. 会計画面 → 「割引」ボタン
2. 割引種類を選択（％割引/金額割引）
3. 割引額を入力

### クーポンを使いたい
1. 会計画面 → 「クーポン適用」ボタン
2. 顧客が持っているクーポンから選択
3. 自動で割引が適用される

### 回数券を消化したい
1. 会計画面 → 「回数券使用」ボタン
2. 使用する回数券を選択
3. 使用回数分が金額から差し引かれる

### ポイントを使いたい
1. 会計画面 → 「ポイント使用」ボタン
2. 使用ポイント数を入力（1P = 1円）
3. 合計金額から差し引かれる

### 複数の支払方法で会計したい（現金＋カード等）
1. 会計画面 → 「分割払い」を選択
2. 1つ目の支払方法と金額を入力
3. 「＋支払方法追加」で2つ目を追加
4. 合計が一致したら「会計確定」

### 会計を取り消したい（返金）
1. **売上管理** → 該当売上を選択
2. 「会計取消」ボタン
3. 理由を入力 → 確認して実行

### 領収書を発行したい
- 会計完了後 → 「領収書発行」ボタン
- または売上詳細 → 「領収書」

## 👤 顧客関連

### 新規顧客を登録したい
1. **顧客管理** → 「＋新規顧客」ボタン
2. 基本情報を入力（名前、電話番号など）
3. 「保存」

### 顧客情報を検索したい
1. **顧客管理** → 検索ボックス
2. 名前、電話番号、メールで検索可能

### 顧客の来店履歴を見たい
1. **顧客管理** → 顧客を選択
2. 「来店履歴」タブ

### 顧客の施術履歴を見たい
1. **顧客管理** → 顧客を選択
2. 「施術履歴」タブで過去のメニュー一覧

### 顧客のポイント残高を確認したい
1. **顧客管理** → 顧客を選択
2. プロフィール画面にポイント残高表示

### 顧客にポイントを付与したい
- 会計時に自動付与（設定による）
- 手動付与：顧客詳細 → 「ポイント調整」

### 顧客にメモを残したい
1. 顧客詳細 → 「メモ」セクション
2. 「＋メモ追加」で記録
3. 施術時の注意点やお好みなどを記入

### 顧客にクーポンを発行したい
1. 顧客詳細 → 「クーポン」タブ
2. 「＋クーポン発行」
3. クーポン種類を選択して発行

### 顧客に回数券を発行したい
1. 顧客詳細 → 「回数券」タブ
2. 「＋回数券発行」
3. 回数券種類を選択して発行

## 👨‍💼 スタッフ関連

### スタッフを追加したい
1. **設定** → **スタッフ管理**
2. 「＋新規スタッフ」ボタン
3. 情報を入力して保存

### スタッフのシフトを設定したい
1. **設定** → **スタッフ管理** → スタッフ選択
2. 「シフト」タブ
3. 曜日ごとの勤務時間を設定

### スタッフの売上を確認したい
1. **レポート** → **スタッフ別売上**
2. 期間を選択して表示

### スタッフの指名売上を見たい
1. **レポート** → **指名分析**
2. スタッフごとの指名率・指名売上を確認

### スタッフを無効化したい（退職など）
1. **設定** → **スタッフ管理** → スタッフ選択
2. 「無効化」ボタン
3. 過去データは保持されつつ、予約受付不可に

## 📋 メニュー関連

### メニューを追加したい
1. **設定** → **メニュー管理**
2. 「＋新規メニュー」ボタン
3. 名前、価格、所要時間、カテゴリを設定

### メニューの価格を変更したい
1. **設定** → **メニュー管理** → メニュー選択
2. 価格を編集 → 「保存」

### メニューを一時的に非表示にしたい
1. **設定** → **メニュー管理** → メニュー選択
2. 「非表示」をONに
3. （削除せずに予約受付を停止）

### カテゴリを追加したい
1. **設定** → **メニュー管理** → 「カテゴリ」タブ
2. 「＋新規カテゴリ」

### 商品（物販）を追加したい
1. **設定** → **商品管理**
2. 「＋新規商品」ボタン
3. 商品情報を入力して保存

---

## 🎫 クーポン・回数券関連

### クーポンマスターを作成したい
1. **設定** → **クーポン管理**
2. 「＋新規クーポン」ボタン
3. 割引条件、有効期限などを設定

### 回数券マスターを作成したい
1. **設定** → **回数券管理**
2. 「＋新規回数券」ボタン
3. 回数、価格、有効期限などを設定

### 発行済みクーポンの一覧を見たい
1. **設定** → **クーポン管理** → 「発行済み」タブ
2. または顧客詳細画面の「クーポン」タブ

### 回数券の残り回数を確認したい
1. 顧客詳細 → 「回数券」タブ
2. 各回数券の残回数が表示

### 期限切れクーポンを確認したい
1. **設定** → **クーポン管理** → 「期限切れ」タブ

## 📊 レポート・分析関連

### 今日の売上を確認したい
- **ホーム画面** のダッシュボードに表示
- または **レポート** → **日次レポート**

### 月間売上を確認したい
1. **レポート** → **売上レポート**
2. 期間を「今月」に設定

### 日報を作成したい
1. **レポート** → **日次レポート**
2. 日付を選択 → 「レポート生成」
3. 売上・来店数・メニュー別集計が自動作成

### 人気メニューを分析したい
1. **レポート** → **メニュー分析**
2. 期間を選択
3. 注文数、売上でランキング表示

### リピート率を確認したい
1. **レポート** → **顧客分析**
2. リピート率、来店頻度のグラフを確認

### 売上目標の達成状況を見たい
1. **レポート** → **売上レポート**
2. 目標対比のグラフで進捗確認

### データをエクスポートしたい
1. 各レポート画面 → 「エクスポート」ボタン
2. CSV形式でダウンロード

## ⚙️ 設定関連

### 店舗の営業時間を変更したい
1. **設定** → **店舗設定**
2. 「営業時間」セクションで編集

### 定休日を設定したい
1. **設定** → **店舗設定**
2. 「定休日」セクションで曜日を選択

### 臨時休業を設定したい
1. **設定** → **店舗設定** → 「臨時休業」
2. 日付を選択して追加

### 消費税率を変更したい
1. **設定** → **基本設定**
2. 「税率」を編集

### ポイント付与率を変更したい
1. **設定** → **ポイント設定**
2. 付与率（例：100円で1ポイント）を設定

### キャンセル料率を変更したい
1. **設定** → **予約設定** → 「キャンセルポリシー」
2. 時間帯別の料率を設定

### 通知設定を変更したい
1. **設定** → **通知設定**
2. リマインダーのタイミング、送信方法を設定

### パスワードを変更したい
1. **設定** → **アカウント設定**
2. 「パスワード変更」

## 🔧 トラブルシューティング

### ログインできない
- パスワードを確認（大文字小文字に注意）
- 「パスワードを忘れた」でリセット
- 管理者に確認（アカウントがロックされている可能性）

### 予約が保存できない
- 必須項目（顧客、メニュー、日時）を確認
- 営業時間外・定休日でないか確認
- スタッフのシフトを確認

### 会計金額が合わない
- 割引・クーポンの適用を確認
- 税込/税抜の設定を確認
- 商品単価を確認

### 画面が動かない・固まった
- ブラウザをリロード（F5 または Ctrl+R）
- ブラウザのキャッシュをクリア
- 別のブラウザで試す

### データが更新されない
- リロードして最新データを取得
- ネットワーク接続を確認
- 他のユーザーが編集中でないか確認

### レポートが表示されない
- 期間設定を確認
- データが存在する期間か確認
- ブラウザをリロード

### 印刷がうまくいかない
- プリンター接続を確認
- ブラウザの印刷設定を確認
- PDF出力してから印刷を試す

## 📱 ショートカット・Tips

### キーボードショートカット
| 操作 | ショートカット |
|------|--------------|
| 新規予約 | `Ctrl + N` |
| 検索 | `Ctrl + F` |
| 保存 | `Ctrl + S` |
| キャンセル | `Esc` |
| 今日に移動 | `T` |

### よく使う操作の高速化
- **クイック予約**: ホーム画面のカレンダーをダブルクリック
- **顧客検索**: 電話番号下4桁でも検索可能
- **直前の予約をコピー**: 予約詳細 → 「コピーして新規作成」

### 便利な機能
- **お気に入り顧客**: よく来る顧客をお気に入り登録
- **メニューセット**: よく使う組み合わせをセット登録
- **定型文**: メモやコメントの定型文を設定
