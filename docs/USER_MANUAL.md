## 1. はじめに

### 1.1 システム概要

Beauty POSは、美容室・サロン向けの統合型POSシステムです。以下の機能を提供します：

- 予約管理・カレンダー
- 来店チェックイン・施術管理
- 会計・レシート発行
- 顧客管理・カルテ
- スタッフ・シフト管理
- 売上レポート・分析
- 通知（LINE/SMS/メール）

### 1.2 対応端末

- **スタッフアプリ**: iPad（iOS 15以上）
- **顧客アプリ**: iPad（店頭設置用）

### 1.3 ユーザー権限

| 権限レベル | できること |
|-----------|-----------|
| オーナー | 全機能 + プラン管理 + 権限設定 |
| 店長 | 店舗内の全機能 + スタッフ管理 + レポート閲覧 |
| スタイリスト | 予約・来店・会計・顧客管理 |
| アシスタント | 予約確認・来店チェックイン（会計は制限付き） |
| 受付 | 予約・来店管理のみ |

## 2. ログイン・認証

### 2.1 ログイン方法

1. アプリを起動
2. **メールアドレス**と**パスワード**を入力
3. 「ログイン」をタップ

### 2.2 パスワードを忘れた場合

1. ログイン画面で「パスワードをお忘れですか？」をタップ
2. 登録済みメールアドレスを入力
3. 届いたメールのリンクからパスワードを再設定

### 2.3 ログアウト

1. 「設定」タブを開く
2. 画面下部の「ログアウト」をタップ
3. 確認ダイアログで「ログアウト」を選択

## 3. ホーム画面

### 3.1 ダッシュボード

ホーム画面では以下の情報を一覧できます：

- **本日の予約件数** - 今日の予約総数
- **待機中のお客様** - チェックイン済み・施術待ちの人数

- **本日の売上** - 当日の売上合計

### 3.2 クイックアクション

- **新規予約** - 予約作成画面へ
- **ウォークイン** - 予約なし来店の登録
- **顧客検索** - 顧客を検索

### 3.3 直近の予約一覧

本日〜明日の予約が時系列で表示されます。タップで詳細を確認できます。

## 4. 予約管理

### 4.1 予約一覧の見方

「予約」タブでは、予約をカレンダー形式で確認できます。

**表示モード:**
- **日表示** - 1日のタイムライン
- **週表示** - 週間カレンダー

**予約の色分け:**
- 🔵 青：確認済み（confirmed）
- 🟡 黄：未確認（pending）
- 🟢 緑：来店済み（checked_in）
- ⚫ グレー：キャンセル済み

### 4.2 新規予約の作成

1. 「＋」ボタンまたは「新規予約」をタップ
2. 以下を入力：
   - **顧客** - 既存顧客を検索 or 新規登録
   - **日時** - 予約日と開始時間
   - **メニュー** - 施術メニューを選択（複数可）
   - **担当スタッフ** - 指名 or フリー
   - **備考** - 要望・注意事項
3. 「予約を作成」をタップ

### 4.3 予約の確認・変更

1. 予約をタップして詳細を開く
2. 「編集」をタップ
3. 変更内容を入力
4. 「保存」をタップ

**変更可能な項目:**
- 日時
- メニュー
- 担当スタッフ
- 備考

### 4.4 予約のキャンセル

1. 予約詳細画面を開く
2. 「キャンセル」をタップ
3. キャンセル理由を入力
4. キャンセル料の確認
   - 48時間以上前：0%
   - 24〜48時間前：30%
   - 24時間以内：50%
   - 当日NoShow：100%
5. 「キャンセルを確定」をタップ

### 4.5 予約通知

予約時に自動で通知が送信されます：
- **予約確認通知** - 予約完了時
- **リマインダー** - 予約前日

## 5. 来店管理

### 5.1 来店一覧

「来店」タブでは、本日の来店状況を確認できます。

**ステータス:**
- ⏳ 待機中（checked_in）
- 💇 施術中（in_service）
- ✅ 完了（completed）

### 5.2 予約ありのチェックイン

1. 予約一覧から該当の予約をタップ
2. 「チェックイン」をタップ
3. 来店一覧に追加されます

### 5.3 ウォークイン（予約なし来店）

1. ホームまたは来店一覧で「ウォークイン」をタップ
2. 顧客を検索 or 新規登録
3. 担当スタッフを選択
4. 「チェックイン」をタップ

### 5.4 施術の開始・終了

**施術開始:**
1. 来店一覧から該当のお客様をタップ
2. 「施術開始」をタップ
3. ステータスが「施術中」に変更

**施術終了:**
1. 施術中のお客様をタップ
2. 「施術終了」をタップ
3. 会計画面へ移動

### 5.5 チェックアウト

会計完了後、自動的にチェックアウトされます。

## 6. 会計（POS）

### 6.1 会計画面の構成

```
┌─────────────────────────────────────┐
│ 顧客名: 田中花子 様                  │
├─────────────────────────────────────┤
│ カート                               │
│ ├ カット          ¥5,000            │
│ ├ カラー          ¥7,000            │
│ └ トリートメント   ¥3,000            │
├─────────────────────────────────────┤
│ 小計             ¥15,000            │
│ 消費税（10%）     ¥1,500            │
│ 合計             ¥16,500            │
├─────────────────────────────────────┤
│ [割引追加] [ポイント利用]            │
│ [支払い方法選択]                     │
│ [会計確定]                          │
└─────────────────────────────────────┘
```

### 6.2 メニュー・商品の追加

1. 「メニュー追加」または「商品追加」をタップ
2. カテゴリから選択 or 検索
3. 数量を指定（デフォルト1）
4. 担当スタッフを設定（技術売上の配分）
5. 「追加」をタップ

### 6.3 ロング料金・指名料の追加

**ロング料金:**
1. メニュー行をタップ
2. 「髪の長さ」を選択（ショート/ミディアム/ロング）
3. 追加料金が自動計算

**指名料:**
1. メニュー行をタップ
2. 「指名タイプ」を選択
3. 指名料が追加

### 6.4 割引の適用

**手動割引:**
1. 「割引追加」をタップ
2. 割引タイプを選択（%割引 or 定額割引）
3. 金額を入力
4. 「適用」をタップ

**クーポン利用:**
1. 「クーポン」をタップ
2. クーポンコードを入力 or 一覧から選択
3. 「適用」をタップ

### 6.5 ポイント利用

1. 「ポイント利用」をタップ
2. 利用ポイント数を入力
3. 「適用」をタップ

※ 1ポイント = 1円として利用可能

### 6.6 回数券の利用

1. 「回数券利用」をタップ
2. 顧客の有効な回数券一覧が表示
3. 使用する回数券を選択
4. 該当メニューの金額が0円に

### 6.7 支払い方法

**対応支払い方法:**
- 💴 現金
- 💳 クレジットカード
- 📱 電子マネー
- 📲 QRコード決済

**複数支払い（分割払い）:**
1. 「支払い方法」をタップ
2. 1つ目の支払い方法と金額を入力
3. 「＋追加」をタップ
4. 2つ目以降の支払い方法と金額を入力
5. 合計が一致したら「確定」

### 6.8 会計の確定

1. 支払い方法を設定
2. 「会計確定」をタップ
3. レシート表示（印刷 or メール送信可）
4. ポイント付与（自動）
5. チェックアウト完了

### 6.9 売上の取り消し（ボイド）

当日の売上は取り消し可能です：

1. 「管理」→「売上履歴」を開く
2. 取り消したい売上をタップ
3. 「取り消し」をタップ
4. 理由を入力
5. 「取り消しを確定」

※ ポイント利用済みの場合、ポイントは自動で返還されます

## 7. 顧客管理

### 7.1 顧客一覧

「顧客」タブで顧客を管理します。

**検索方法:**
- 名前（漢字・ひらがな・カタカナ）
- 電話番号
- 顧客コード

### 7.2 新規顧客登録

1. 「＋」ボタンをタップ
2. 基本情報を入力：
   - 姓名（必須）
   - 電話番号
   - メールアドレス
   - 生年月日
   - 性別
3. 「登録」をタップ

### 7.3 顧客詳細画面

顧客をタップすると詳細画面が開きます：

- **基本情報** - 連絡先、来店回数、累計金額
- **カルテ** - 髪質情報、アレルギー、注意事項
- **来店履歴** - 過去の来店と施術内容
- **ポイント** - 現在の保有ポイント
- **回数券** - 有効な回数券一覧

### 7.4 カルテの管理

**髪質情報:**
- 毛量（少ない/普通/多い）
- 髪の太さ（細い/普通/太い）
- 髪の硬さ（軟毛/普通/硬毛）
- クセの強さ（直毛/弱いクセ/強いクセ）
- ダメージレベル（なし/軽度/中度/重度）

**カラーレシピ:**
過去のカラー配合を記録・参照できます：
- 使用薬剤
- 配合比率
- 放置時間
- 仕上がり写真

### 7.5 施術写真の管理

Before/After写真を顧客ごとに保存：

1. 顧客詳細の「写真」タブを開く
2. 「＋」をタップ
3. カメラで撮影 or ギャラリーから選択
4. タイプを選択（Before/After/スタイル）
5. 「保存」をタップ

### 7.6 タグ管理

顧客にタグを付けて分類できます：
- VIP
- 新規
- 紹介
- 注意
- カスタムタグ

### 7.7 ブラックリスト

問題のある顧客をブラックリストに追加：

1. 顧客詳細を開く
2. 「︙」メニューをタップ
3. 「ブラックリストに追加」を選択
4. 理由を入力
5. 予約時に警告が表示されるようになります

## 8. スタッフ管理

### 8.1 スタッフ一覧

「管理」→「スタッフ管理」で確認できます。

### 8.2 スタッフ登録

1. 「＋」ボタンをタップ
2. 情報を入力：
   - 氏名
   - メールアドレス
   - 役職（スタイリスト/アシスタント等）
   - 指名料
3. 「登録」をタップ

### 8.3 シフト管理

1. 「管理」→「シフト管理」を開く
2. カレンダーでスタッフごとのシフトを確認
3. 日付をタップしてシフトを追加/編集

**シフトのコピー:**

1. 「週をコピー」をタップ
2. コピー元の週を選択
3. 「コピー実行」をタップ

### 8.4 勤怠管理

スタッフ自身が打刻します：

**出勤:**
1. ホーム画面で「出勤」をタップ
2. 出勤時刻が記録されます

**退勤:**
1. ホーム画面で「退勤」をタップ
2. 退勤時刻が記録されます

### 8.5 権限設定

オーナー・店長のみ設定可能：

1. 「管理」→「権限管理」を開く
2. スタッフを選択
3. 権限をON/OFFで設定
4. 「保存」をタップ

## 13. トラブルシューティング

### 13.1 よくある質問

**Q: ログインできない**
A: パスワードリセットを試すか、管理者に連絡してください。

**Q: 予約が表示されない**
A: 日付フィルターを確認してください。「全て表示」に切り替えると確認できます。

**Q: 会計でエラーが出る**
A: ネットワーク接続を確認してください。オフライン時は会計できません。

**Q: レシートが印刷されない**
A: プリンターの接続状態とペーパーを確認してください。

**Q: ポイントが付与されない**
A: ポイント機能が有効になっているか「機能設定」で確認してください。

### 13.2 エラーコード一覧

| コード | 意味 | 対処法 |
|--------|------|--------|
| E001 | ネットワークエラー | インターネット接続を確認 |
| E002 | 認証エラー | 再ログインしてください |
| E003 | 権限エラー | 管理者に権限付与を依頼 |
| E004 | データ不整合 | サポートに連絡 |
| E005 | サーバーエラー | しばらく待って再試行 |
