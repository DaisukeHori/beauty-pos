## 1. 予約管理

### 1.1 予約一覧・カレンダー

| 機能 | 説明 |
|------|------|
| 日表示 | 1日のタイムラインで予約を表示 |
| 週表示 | 週間カレンダー形式で予約を俯瞰 |
| スタッフ別表示 | スタッフごとの予約状況を並列表示 |
| ステータス色分け | 予約状態を色で視覚的に識別 |
| リアルタイム更新 | Supabase Realtimeで自動同期 |
| ドラッグ&ドロップ | 予約の日時変更をドラッグ操作で |

**予約ステータス:**
- `pending` - 未確認
- `confirmed` - 確認済み
- `checked_in` - 来店済み
- `completed` - 完了
- `canceled` - キャンセル
- `no_show` - 無断キャンセル

### 1.2 予約作成

| 機能 | 説明 |
|------|------|
| 顧客検索・選択 | 既存顧客を名前・電話番号で検索 |
| 新規顧客登録 | 予約作成時に新規顧客を同時登録 |
| スタッフ指名 | 担当スタイリストを指名 or フリー |
| メニュー選択 | 複数メニューを選択可能 |
| 日時選択 | カレンダーと時間ピッカーで選択 |
| 所要時間自動計算 | メニューから所要時間を自動算出 |
| 予約メモ | 要望・注意事項を記録 |
| ブラックリスト警告 | 問題顧客の予約時に警告表示 |

### 1.3 空き時間検索

| 機能 | 説明 |
|------|------|
| スタッフシフト考慮 | 勤務時間内のみ表示 |
| 営業時間考慮 | 店舗営業時間内のみ |
| 休憩時間除外 | スタッフ休憩を自動除外 |
| 既存予約チェック | 重複予約を自動防止 |
| 30分単位スロット | 予約可能枠を30分刻みで生成 |
| 複数日候補表示 | 複数日の空き状況を一覧表示 |

### 1.4 予約重複チェック

| 機能 | 説明 |
|------|------|
| スタッフ重複防止 | 同一スタッフの同時間帯予約を防止 |
| 席数チェック | 店舗の座席数を超える予約を防止 |
| シフト外警告 | シフト時間外の予約に警告 |
| 定休日警告 | 定休日への予約に警告 |

### 1.5 予約操作

| 機能 | 説明 |
|------|------|
| 予約確認 | ステータスを confirmed に変更 |
| 予約変更 | 日時・メニュー・スタッフの変更 |
| 予約キャンセル | キャンセル理由と料金を記録 |
| NoShow記録 | 無断キャンセルを記録 |
| 来店登録 | 来店管理へ移行（チェックイン） |
| 予約コピー | 同じ内容で新規予約を作成 |

### 1.6 予約通知

| 機能 | 説明 |
|------|------|
| 予約確認通知 | 予約完了時に自動送信 |
| リマインダー（前日） | 予約前日に送信 |
| リマインダー（当日） | 予約3時間前に送信 |
| キャンセル通知 | キャンセル時に自動送信 |
| 変更通知 | 予約変更時に自動送信 |
| LINE/SMS/メール | 複数チャネルに対応 |

## 2. キャンセル・NoShow管理

### 2.1 キャンセル料金システム

| 機能 | 説明 |
|------|------|
| 時間帯別料金 | 予約までの時間でキャンセル料を段階設定 |
| 自動計算 | キャンセル時に料金を自動算出 |
| 見積表示 | キャンセル前に料金を事前表示 |
| 料金徴収記録 | 徴収したキャンセル料を記録 |

**キャンセル料金ルール例:**
| タイミング | 料金率 |
|-----------|--------|
| 48時間以上前 | 0% |
| 24〜48時間前 | 30% |
| 24時間以内 | 50% |
| 当日NoShow | 100% |

### 2.2 NoShow管理

| 機能 | 説明 |
|------|------|
| NoShow記録 | 無断キャンセルを専用ステータスで記録 |
| NoShow回数追跡 | 顧客ごとのNoShow履歴を集計 |
| 自動ブラックリスト | 一定回数で自動的にブラックリスト化 |
| NoShow料金請求 | 100%のキャンセル料を設定 |

### 2.3 ブラックリスト管理

| 機能 | 説明 |
|------|------|
| 手動登録 | 問題顧客を手動でブラックリスト追加 |
| 自動登録 | NoShow回数超過で自動追加 |
| 理由記録 | ブラックリスト理由を記録（no_show_limit/manual/fraud） |
| 予約時警告 | ブラックリスト顧客の予約時に警告表示 |
| 危機顧客警告 | ブラックリスト寸前の顧客に警告 |
| 解除機能 | ブラックリストからの解除も可能 |

### 2.4 キャンセル履歴

| 機能 | 説明 |
|------|------|
| キャンセル回数 | 顧客ごとのキャンセル回数を集計 |
| NoShow回数 | 顧客ごとのNoShow回数を集計 |
| 支払い罰金額 | 徴収したキャンセル料の累計 |
| 履歴検索 | 期間・顧客でキャンセル履歴を検索 |

## 3. 来店管理

### 3.1 来店一覧

| 機能 | 説明 |
|------|------|
| 本日来店一覧 | 当日の来店状況を一覧表示 |
| ステータス絞り込み | 待機中/施術中/完了で絞り込み |
| 待ち時間表示 | チェックインからの経過時間を表示 |
| リアルタイム更新 | 来店状況を自動同期 |

**来店ステータス:**
- `checked_in` - 待機中
- `in_service` - 施術中
- `completed` - 完了

### 3.2 来店登録

| 機能 | 説明 |
|------|------|

| 顧客検索 | 既存顧客を検索して来店登録 |
| 新規顧客登録 | 来店と同時に新規顧客作成 |
| 担当スタッフ割当 | primary/assistantを設定 |

### 3.3 来店操作

| 機能 | 説明 |
|------|------|
| 施術開始 | ステータスを in_service に変更 |
| 施術完了 | 会計画面へ移行 |
| 来店情報編集 | メニュー・スタッフの変更 |
| 来店キャンセル | 来店後のキャンセル処理 |

### 3.4 チェックイン/チェックアウト

| 機能 | 説明 |
|------|------|
| チェックイン時刻 | 来店時刻を自動記録 |
| チェックアウト時刻 | 会計完了時に自動記録 |
| 待機時間計算 | チェックインから施術開始までの時間 |
| 滞在時間計算 | チェックインからチェックアウトまでの時間 |
